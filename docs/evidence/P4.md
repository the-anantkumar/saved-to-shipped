# P4: hosted browser workflow

Status: implemented and verified locally on 2026-11-07. The preceding backend checkpoint is `09589f9`; the commit containing this record adds the browser integration. Real Google authentication remains a live canary gate. Owner: `beta_product`; coordinator integrates and commits; independent security reviewer checked the shared identity/API boundaries.

The Python-served HTML remains account-free. A separate build copies its assets, injects the hosted bootstrap and bundles only Firebase app/auth plus bounded ZIP support. The generated directory is recreated to exclude stale assets. A release checker verifies source/bundle freshness, exact asset inventory and absence of synthetic identity entrypoints, Firestore and gRPC in the browser graph.

Hosted transport uses managed Firebase persistence and a memory-only workspace capability. Lists load metadata; source text and notes load on demand. Reads may renew authentication once, but writes and paid submissions are never automatically retried. Account switching aborts pending work and clears private caches. Conflicts retain unsaved drafts. Imports parse Saved Items locally in a bounded worker and send reviewed chunks; selecting a file again creates a new operation while URL deduplication preserves existing work. V1 exports/restores retain annotations and reading state without provider keys.

The interface preserves Saves, Projects, Learning and Experiences, inline section creation, independent notes, reading completion, keyboard movement, pointer dragging without page selection, and mobile/dark layouts. A frozen deletion has a dedicated recovery gate with recent reauthentication, immediate replacement-key field clearing and bearer-only cleanup retries.
